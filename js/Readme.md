# 🚀 Las Avneturas de Bengi - Landing Page

## 🛠️ Tecnologías Utilizadas

* **JavaScript (ES6+):** Lógica modular con archivos JS (`theme.js`, `main.js`) para mantenibilidad.
* **LocalStorage:** Implementación de persistencia de datos para el **Modo Oscuro**.
* **Bootstrap 5 & Custom CSS:** Maquetación responsiva con soporte nativo de `data-bs-theme`.
* **Render | The cloud for builders:** es la plataforma en la nube moderna diseñada precisamente para esta trayectoria, lo que le permite desplegar y escalar sin problemas cualquier aplicación.

## ⚙️ Funcionalidades Clave

1. **Validación de Formularios:** Feedback visual inmediato para el usuario antes del envío.
2. **Experiencia de Usuario (UX):** El sitio recuerda la preferencia de tema (Oscuro/Claro) del usuario mediante LocalStorage.
